# 单笔订单开票（invoice-apply.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/invoice-apply.vue` |
| 路由地址 | `/invoice-apply` |
| 路由名称 | `invoice-apply` |
| 业务分组 | 合同与发票 |
| 页面标题 | 单笔订单开票 |

## 页面作用

针对单笔订单填写开票信息：发票类型（增值税普通/专用发票）、企业抬头、统一社会信用代码、电子发票接收邮箱；必填校验通过后跳转发票详情页。

## 数据来源

- 路由 `query.id`：关联订单号，仅透传，不回查订单内容
- 本地 data：`type`（默认"增值税普通发票"）、`title`、`taxId`、`email`，均为页面内表单状态
- 校验提示通过 mutation `setNotice` 写入全局轻提示

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 选择发票类型 | 切换下拉框 | `v-model` 绑定 `type`，可选普票/专票 |
| 填写抬头/税号/邮箱 | 输入框输入 | `v-model.trim` 自动去除首尾空格 |
| 保存演示申请 | 点击"保存演示申请" | 三项必填任一为空时 commit `setNotice`（"请填写企业抬头、税号和邮箱"）并中断；全部填写后跳转 `/invoice-detail`，query 仅携带 `id` 与 `title` |

## 依赖的组件或工具

- Vuex：mutation `setNotice`（全局轻提示）
- vue-router：跳转发票详情页
- 无接口调用、无领域工具函数

## 状态与边界

- 演示申请不提交服务器、不落库，跳转后除抬头外的表单数据不保留
- 仅做非空校验，不校验税号格式、邮箱格式与抬头真实性
- 发票类型固定两个选项；开票资格、税率和金额文案注明由订单与发票接口校验
