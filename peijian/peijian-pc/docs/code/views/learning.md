# 学习专区（learning.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/learning.vue` |
| 路由地址 | `/learning` |
| 路由名称 | `learning` |
| 业务分组 | 内容与服务 |
| 页面标题 | 学习专区 |

## 页面作用

以卡片列表形式聚合展示操作视频、产品手册和行业动态等学习内容，每张卡片显示分类角标、标题、简介、日期与标签，点击卡片进入学习内容详情页。

## 数据来源

- 本地 mock 文件 `@/mock/catalog.json` 的 `contents` 数组，组件初始化时整体读入 `data.contents`
- 每条内容字段：`id`、`title`（标题）、`cat`（分类）、`desc`（简介）、`date`（日期）、`tag`（标签，如视频时长）等
- 无 Vuex 读取，无接口调用

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 查看内容详情 | 点击任意内容卡片 | 跳转 `/article?id={内容id}` |

## 依赖的组件或工具

- `router-link`：卡片整体作为跳转链接
- 本地 mock：`@/mock/catalog.json`
- 全局样式类：`three-col`、`card`、`badge blue`

## 状态与边界

- 内容为写死在 `catalog.json` 中的演示数据，无分类筛选、搜索、分页或加载更多
- 正式的视频/手册/资讯列表及阅读量（`read` 字段当前未在本页展示）均待内容接口提供
