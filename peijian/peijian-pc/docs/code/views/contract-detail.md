# 合同预览与回传（contract-detail.vue）

| 项目     | 说明                            |
| -------- | ------------------------------- |
| 文件路径 | `src/views/contract-detail.vue` |
| 路由地址 | `/contract-detail`              |
| 路由名称 | `contract-detail`               |
| 业务分组 | 合同与发票                      |
| 页面标题 | 合同预览与回传                  |

## 页面作用

在 `sheet-doc` 卡片中展示完整采购合同资料：合同编号、订单编号、标题、签署状态徽章、买方企业与税号、卖方企业、生成/签署时间、合同金额与合同条款。已生效合同提供下载按钮（演示仅提示），待买方签署合同保留 PDF 回传入口（不真正上传）；按 id 查不到合同时展示"待平台生成"占位卡片。

## 数据来源

- `businessApi.contractDetail(query.id)`：`created` 时拉取，mock 模式读取 `catalog.json` 的 `contracts`，匹配条件为 `c.id === id || c.orderId === id`，即**支持用合同号或订单号查询**，找不到时返回 `null`
- 本地 data `file`：文件选择框记录的回传 PDF 文件名，仅用于页面提示，不参与任何请求
- 合同金额 `amountFen` 经 `money(fen)` 格式化

## 交互说明

| 操作         | 触发                                   | 行为                                                                                        |
| ------------ | -------------------------------------- | ------------------------------------------------------------------------------------------- |
| 下载合同 PDF | 已生效合同点击"下载合同 PDF"           | 调用 `download()` 提交 Vuex `setNotice`："演示环境不生成真实合同文件"，不产生真实文件       |
| 回传文件     | 点击"回传文件"（待签署合同或占位卡片） | 隐藏的 `<input type="file" accept=".pdf">` 打开选择器，`change` 后仅把文件名写入本地 `file` |
| 文件已选提示 | `file` 非空时                          | 卡片底部显示"已选择：xxx（演示，未上传服务器）"                                             |
| 状态徽章     | 渲染时由 computed `statusClass` 配色   | "已生效"为 `green`，否则为 `gold`                                                           |

## 依赖的组件或工具

- `businessApi`：`@/api` 的合同详情接口（支持合同号/订单号）
- `money(fen)`：来自 `@/domain/productFields`
- Vuex：`commit('setNotice')` 全局轻提示
- vue-router：通过 `$route.query` 读取 id

## 状态与边界

- 仅当接口按 id 查不到合同时才渲染"待平台生成"占位卡片（合同编号"待平台生成"、买方"待企业认证资料回填"、状态"待生成"、下载按钮 `disabled`），占位卡片仍可选择回传文件
- 回传文件仅在浏览器本地记录名称，不上传服务器、不校验大小与有效性，刷新即丢失
- 合同正文、金额及双方主体以合同接口返回为准
