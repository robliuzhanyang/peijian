# 消息通知（messages.vue）

| 项目     | 说明                     |
| -------- | ------------------------ |
| 文件路径 | `src/views/messages.vue` |
| 路由地址 | `/messages`              |
| 路由名称 | `messages`               |
| 业务分组 | 内容与服务               |
| 页面标题 | 消息通知                 |

## 页面作用

展示订单、售后、发票、合同与系统五类消息通知列表：顶部在有未读时显示未读数徽章；每条消息展示类型汉字图标、标题（未读标题前带红点）、右对齐时间与正文内容；点击整条消息可在本地标记为已读。

## 数据来源

- `businessApi.messages()`：`created` 时调用 `loadMessages()` 拉取消息数组并写入本地 data `messages`；mock 模式读取 `catalog.json` 的 `messages`（种子 7 条，已按时间倒序，字段含 `type`、`title`、`content`、`time`、`read`）
- 未读数不单独请求，由 computed `unreadCount` 对本地 `messages` 中 `read === false` 的项计数

## 交互说明

| 操作         | 触发                                   | 行为                                                                                          |
| ------------ | -------------------------------------- | --------------------------------------------------------------------------------------------- |
| 未读数提示   | 列表上方条件渲染                       | `unreadCount` 大于 0 时显示红色徽章"N 条未读"；全部已读后该行不渲染                           |
| 未读红点     | 单条消息标题前                         | `read` 为 false 时显示红色小圆点，标记已读后消失                                              |
| 点击已读     | 点击整条消息（`@click="markRead(m)"`） | 仅把本地 data 中该项 `read` 置为 true，不调接口、不持久化                                     |
| 消息类型图标 | 渲染时由 `typeLabel` 映射为两个汉字    | order→ 订单、aftersale→ 售后、invoice→ 发票、contract→ 合同、system→ 系统；未知类型兜底"系统" |

## 依赖的组件或工具

- `businessApi`：`@/api` 的消息通知列表接口
- Vuex：无数据依赖（已读仅操作本地 data）
- 全局样式类：`card`、`between`、`message`、`message-icon`、`tiny`、`badge`、`empty`
- 组件声明为 `{ name: 'Page' }`

## 状态与边界

- 已读状态只在组件本地 data 生效，不调接口、不持久化；刷新页面后恢复为接口返回的已读标记（mock 模式即种子值）
- 无消息分类 Tab、分页或跳转，整条点击只标记已读，不跳转到业务详情
- 消息列表为空时显示"暂无消息。"
- mock 模式消息为 `catalog.json` 种子数据，正式消息列表、未读数与已读同步以消息接口为准
