# 物流跟踪（logistics.vue）

| 项目     | 说明                      |
| -------- | ------------------------- |
| 文件路径 | `src/views/logistics.vue` |
| 路由地址 | `/logistics`              |
| 路由名称 | `logistics`               |
| 业务分组 | 交易与履约                |
| 页面标题 | 物流跟踪                  |

## 页面作用

展示订单物流信息：有轨迹时呈现物流公司、运单号、收货提示与物流轨迹时间线；当按订单 id 查不到物流数据（如未发货订单）时，回退展示"履约时间线"无数据占位，不虚构物流信息。

## 数据来源

- `businessApi.logistics(query.id)`（来自 `@/api`）：`created` 时按路由订单 id 拉取 `{ company, waybill, nodes: [{ time, title, desc, state }] }`；mock 模式读取 `catalog.json` 的 `logistics`（以订单 id 为键，种子覆盖 3 笔已发出订单），查无此键时返回 `null`
- 路由 `query.id`：作为接口入参并在页头展示订单号，缺省时页头显示"待选择"

## 交互说明

| 操作           | 触发                           | 行为                                                                                                                                   |
| -------------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 物流信息卡     | 接口返回数据时渲染             | 展示物流公司、运单号与签收核对提示文案                                                                                                 |
| 物流轨迹时间线 | 接口返回数据时渲染             | 逐条渲染 `nodes`（种子数据已按时间倒序，最新节点在首条并命中首节点高亮样式）；`state` 为 `todo` 的节点标题/时间用 `field-pending` 弱化 |
| 无数据占位     | `logistics` 为 `null` 时渲染   | 展示订单提交（已记录）、支付/核款（以订单状态为准）、备货与出库、运输/签收（后两项为"待物流接口回传"）及占位说明 `alert`               |
| 返回订单       | 点击"返回订单"（仅占位卡片内） | 路由跳转 `/orders`                                                                                                                     |

## 依赖的组件或工具

- `businessApi`：`@/api` 的物流轨迹接口
- vue-router：通过 `$route.query` 取订单 id，`<router-link>` 返回订单列表
- 全局样式类：`card`、`timeline`、`timeline-node`、`field-pending`、`alert`
- 组件声明为 `{ name: 'Page' }`

## 状态与边界

- 仅当接口查不到该订单的物流数据时才显示无数据占位，占位不生成虚构的公司、运单号与轨迹
- 不校验订单 id 是否真实存在，任意 id 查不到数据时都走占位分支
- 正式物流公司、运单号与轨迹以物流接口返回为准
