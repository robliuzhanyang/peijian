# 商城首页（home.vue · PC 版）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/home.vue` |
| 路由地址 | `/home` |
| 路由名称 | `home` |
| 业务分组 | 采购入口 |
| 页面标题 | 商城首页 |

## 页面作用

PC 宽屏首页：品牌采购主张 Hero 区、四个采购入口宫格、客户资料产品陈列与热销演示商品。

## 数据来源

读取 Vuex `state.products`，在 computed 中分组：

- `customer`：`sourceType === 'customer'` 的客户资料产品
- `hot`：`hot` 标记的商品取前 4 条

## 页面结构

1. Hero 区：工业配件一站式选型主张 + "开始采购"按钮 + 设备示意图
2. 入口宫格：配件采购、套装直购、模块化选配、企业工作台
3. 客户资料产品区（含"查看全部配件"链接）
4. 热销演示商品区（最多 4 个，附演示价格声明）

## 依赖的组件

- [ProductCard](../../components/ProductCard.md)
- 领域工具 `asset`（静态资源路径）

## 与 H5 版差异

H5 首页（`h5-vue/src/views/home.vue`）文案更简短，第四个入口为"订单"，且无"查看全部配件"链接；两端独立维护。

## 状态与边界

价格与库存为演示信息，客户资料产品多为待报价状态，正式数据以接口为准。
