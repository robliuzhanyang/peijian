# 支付失败（pay-failed.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/pay-failed.vue` |
| 路由地址 | `/pay-failed` |
| 路由名称 | `pay-failed` |
| 业务分组 | 交易与履约 |
| 页面标题 | 支付失败 |

## 页面作用

演示支付未完成的结果反馈页，提示用户可返回订单重新选择支付方式，并给出"查看订单"和"返回首页"两个出口。

## 数据来源

- 无任何数据读取（不读路由参数、不读 Vuex、不调接口），纯原型占位页

## 交互说明

无交互，仅展示原型占位。

## 依赖的组件或工具

- vue-router `<router-link>`：跳转订单列表 `/orders` 与首页 `/home`
- 组件声明为 `{ name: 'Page' }`，无业务工具依赖

## 状态与边界

- 纯结果占位页，不改变订单状态，也不携带订单 id，用户需从订单列表自行找到待付款订单
- 因是演示页，支付失败不区分具体失败原因
