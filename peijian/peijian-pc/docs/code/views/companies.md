# 切换企业（companies.vue）

| 项目     | 说明                      |
| -------- | ------------------------- |
| 文件路径 | `src/views/companies.vue` |
| 路由地址 | `/companies`              |
| 路由名称 | `companies`               |
| 业务分组 | 企业与账号                |
| 页面标题 | 切换企业                  |

## 页面作用

展示同一账号下可切换的企业列表：每行显示企业名称、"当前企业"徽章、认证状态徽章、角色、统一社会信用代码与联系人电话；非当前企业提供"切换"按钮，底部提供提交新企业认证入口。

## 数据来源

- `businessApi.companies()`：`created` 时调用 `load()` 拉取企业数组（try/catch，失败时回退为空数组），mock 模式读取 `catalog.json` 的 `companies`（种子 3 家：C1 深圳市精刻（current=true，已认证）、C2 东莞精刻（认证中）、C3 广州精刻（已认证））
- 每项字段：`id`、`name`、`taxId`、`contact`、`phone`、`role`、`status`、`current`

## 交互说明

| 操作           | 触发                     | 行为                                                                                                              |
| -------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 当前企业标识   | 列表渲染                 | `current` 为 true 的企业名称后显示蓝色"当前企业"徽章，且不显示"切换"按钮                                          |
| 认证状态徽章   | 列表渲染                 | 状态为"已认证"时 `green`，其余状态（认证中）为 `gold`                                                             |
| 切换企业       | 点击非当前企业行的"切换" | 调用 `switchTo(c)`，仅提交 Vuex `setNotice`："演示环境：切换企业需重新登录鉴权，正式版以接口为准"，不建立真实会话 |
| 提交新企业认证 | 点击底部主按钮           | 路由跳转 `/register`                                                                                              |

## 依赖的组件或工具

- `businessApi`：`@/api` 的可切换企业列表接口
- Vuex：`commit('setNotice')` 全局轻提示
- vue-router：跳转注册/企业认证页
- 全局样式类：`card`、`order-line`、`tiny`、`badge`、`btn`、`empty`
- 组件声明为 `{ name: 'Page' }`

## 状态与边界

- 企业列表为空时显示"暂无可切换的企业身份。"空态
- 接口异常被 catch 后 `companies` 回退为空数组，页面保持空态
- 切换操作仅为演示提示，不改变当前企业与会话；多企业身份、权限与真实切换鉴权以接口和登录体系为准
