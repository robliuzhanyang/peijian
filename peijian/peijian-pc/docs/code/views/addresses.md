# 收货地址（addresses.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/addresses.vue` |
| 路由地址 | `/addresses` |
| 路由名称 | `addresses` |
| 业务分组 | 企业与账号 |
| 页面标题 | 收货地址 |

## 页面作用

以双列卡片形式展示企业常用收货地址（收货人、电话、完整地址），默认地址带"默认"角标，底部提供"新增地址"入口。

## 数据来源

- `state.addresses`：Vuex 收货地址数组，每项含 `id`、`name`、`phone`、`full`、`primary`
- 地址数据本地持久化；store 中无记录时内置一条演示默认地址（`primary: true`）
- 新增地址由地址编辑页通过 mutation `addAddress` 写入

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 新增地址 | 点击"新增地址" | 路由跳转 `/address-edit` |

页面本身无选择、编辑、删除地址的操作，地址卡片不可点击。

## 依赖的组件或工具

- `router-link`：跳转新增地址页
- Vuex：读取 `state.addresses`

## 状态与边界

- 页面未实现空列表态（store 始终兜底一条演示默认地址）
- 新增地址的 `primary` 固定为 `false`，本页不提供设为默认/编辑/删除入口
- 地址为本地持久化的演示数据，未与服务端企业地址同步
