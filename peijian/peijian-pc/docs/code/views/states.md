# 状态与异常样式（states.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/states.vue` |
| 路由地址 | `/states` |
| 路由名称 | `states` |
| 业务分组 | 原型验收 |
| 页面标题 | 状态与异常样式 |

## 页面作用

原型验收入口页，用三张卡片集中展示三类异常/空态视觉样式：资料缺失、待报价、空列表，并附对应页面的跳转入口便于核对。纯静态样式集合页。

## 数据来源

- 无动态数据来源，无接口调用、无组件 `data`

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 查看常规立柱详情 | 点击"常规立柱详情" | 路由跳转 `/detail?id=columnStandard`，核对资料缺失样式在详情页的表现 |
| 不可购买 | 点击"不可购买"按钮 | 按钮为 `disabled` 禁用状态，无行为 |
| 查看搜索空态 | 点击"查看搜索空态" | 路由跳转 `/search?q=not-found`，核对搜索无结果空态 |

## 依赖的组件或工具

- `router-link`：跳转详情页与搜索页
- 全局样式类：`field-pending`（资料缺失占位）、`price`（待报价）、`card`、`btn` 等

## 状态与边界

- 本页仅用于验收视觉样式，不承载任何业务逻辑与数据
- 三张卡片的内容均为固定文案，真实页面的异常态以各业务页接口返回为准
