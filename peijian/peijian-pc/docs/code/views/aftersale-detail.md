# 售后进度（aftersale-detail.vue）

| 项目     | 说明                             |
| -------- | -------------------------------- |
| 文件路径 | `src/views/aftersale-detail.vue` |
| 路由地址 | `/aftersale-detail`              |
| 路由名称 | `aftersale-detail`               |
| 业务分组 | 内容与服务                       |
| 页面标题 | 售后进度                         |

## 页面作用

展示单个售后工单的完整详情：工单号、关联订单号、申请类型、工单状态徽章、问题描述、申请时间，并以时间线展示处理进度（多节点按倒序渲染，最新节点置顶）。query.id 可以是工单号，也可以是从申请页带入的订单号；查不到工单时回退展示演示申请占位。

## 数据来源

- `businessApi.aftersaleDetail(id)`：`created` 时调用 `loadDetail()` 拉取，mock 模式读取 `catalog.json` 的 `aftersales`，匹配条件为 `a.id === id || a.orderId === id`（支持工单号或订单号查询），找不到返回 `null`
- 路由 `query.type`：占位分支的申请类型兜底文案
- 进度时间线取工单的 `steps: [{ title, desc, time, state }]`；种子数据中"处理中"工单为 5 步（提交申请 → 客服审核 → 寄回检测 → 换货发出 → 完成，当前停在寄回检测），"已完成"工单为 4 步

## 交互说明

| 操作         | 触发                                       | 行为                                                                                                                         |
| ------------ | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 进度时间线   | 查到工单时由 computed `reversedSteps` 渲染 | 对 `steps` 复制后倒序，最新节点排第一并命中首节点高亮；节点有 `time` 显示时间，无 `time` 以 `field-pending` 显示"时间待更新" |
| 工单状态徽章 | 渲染时由 `statusClass` 配色                | 处理中 `gold`、已完成 `green`、待审核 `blue`、已拒绝 `red`，未知状态无配色                                                   |
| 返回售后列表 | 点击"返回售后列表"                         | 路由跳转 `/aftersales`                                                                                                       |

页面无提交、取消等工单写操作。

## 依赖的组件或工具

- `businessApi`：`@/api` 的售后工单详情接口（支持工单号/订单号）
- vue-router：通过 `$route.query` 读取 id/type，`<router-link>` 返回列表
- 全局样式类：`card`、`order-line`、`timeline`、`timeline-node`、`field-pending`、`badge`
- 组件声明为 `{ name: 'Page' }`

## 状态与边界

- 仅当按 id 查不到工单（如申请页刚提交、服务端尚未生成工单）时才渲染申请占位：申请类型取 `query.type` 或"待接口返回"，工单状态显示"演示申请，待提交服务端"，并提示售后资格、退款金额及工单流转由服务端判定
- 路由不带 id 时不发起接口请求，页面直接停留占位
- mock 模式工单为 `catalog.json` 种子数据，正式进度节点以售后接口返回为准
