# 我的订单（orders.vue）

| 项目     | 说明                   |
| -------- | ---------------------- |
| 文件路径 | `src/views/orders.vue` |
| 路由地址 | `/orders`              |
| 路由名称 | `orders`               |
| 业务分组 | 交易与履约             |
| 页面标题 | 我的订单               |

## 页面作用

按订单状态筛选展示订单列表，每行显示订单号与状态徽章、下单时间、商品摘要（反查商品库名称，最多展示 2 项）、订单金额，并提供进入订单详情的入口。

## 数据来源

- `state.orders`：订单列表。仓库初始化时把 `catalog.json` 的 `orders` 种子（8 笔，覆盖待付款/待核款/待发货/运输中/待收货/售后中/已完成/已取消）与本地订单按 id 做一次性合并，并写入 localStorage 持久化（PC 端键 `xinjian-pc-v3`，带 `seeded` 标记，标记后再次加载完全以本地为准）；本机新下单由 `addOrder` unshift 置顶
- `getters.product(productId)`：在 `summary` 中按行项 `productId` 反查商品名称，目录中查不到时回显行项 `skuCode`
- 金额取订单创建时的快照 `totalFen`，经 `money(fen)` 格式化为元
- 状态筛选不分页、不调接口，在 `computed.filtered` 中按本地 `status` 前端过滤

## 交互说明

| 操作         | 触发                                                                                | 行为                                                                                     |
| ------------ | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 切换状态筛选 | 点击分段按钮（全部/待付款/待核款/已付款/待发货/运输中/待收货/已完成/已取消/售后中） | 更新本地 `status`，列表实时过滤，当前项加 `on` 高亮                                      |
| 查看详情     | 点击"查看详情"                                                                      | 携带订单 id 跳转 `/order-detail?id={订单id}`                                             |
| 状态徽章     | 列表渲染时由 `badgeClass` 配色                                                      | 已完成 `green`、售后中 `gold`、已取消 `red`、待付款/待核款 `orange`，其余状态 `blue`     |
| 商品摘要     | 列表渲染时由 `summary` 生成                                                         | 拼接"商品名 × 数量"，最多 2 项；超过 2 项追加"等 N 类商品"；下单时间缺失显示"时间待确认" |

## 依赖的组件或工具

- `money(fen)`：来自 `@/domain/productFields`
- Vuex：读取 `state.orders` 与 getter `product`
- vue-router：跳转订单详情页
- 全局样式类：`card`、`segment`、`order-line`、`badge`、`price`、`empty`

## 状态与边界

- 当前筛选状态下无订单时显示"该状态暂无订单。"空态及"去选购"（`/goods`）链接
- 筛选条件为前端固定枚举（含种子数据未出现的"已付款"），订单状态若超出枚举范围将无法被对应标签筛出（"全部"仍可见）
- 订单金额与商品行项均为下单时快照，不随后续价格变化；商品在目录中反查不到时摘要回显 SKU 编码
- mock 模式订单为 `catalog.json` 种子数据，正式数据以订单接口返回为准
