# 配件采购（goods.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/goods.vue` |
| 路由地址 | `/goods` |
| 路由名称 | `goods` |
| 业务分组 | 采购入口 |
| 页面标题 | 配件采购 |

## 页面作用

商品采购列表页：支持按名称/型号/SKU 关键词、分类下拉进行筛选，并可按价格从低到高排序；结果以商品网格展示，无匹配时显示空态。可接收分类页传入的 `cat` 参数和搜索/外链传入的 `q` 参数。

## 数据来源

全部来自 Vuex，筛选在前端内存中完成：

- `state.products`：商品目录；计算属性 `products` 先按关键词（匹配 `name`、`model`、`skuCode`、`series`，不区分大小写）与分类 `cat` 过滤，再按 `sort` 决定是否按 `priceFen` 升序（无价格商品排最后）
- `state.categories`：分类下拉选项
- 筛选条件 `q`、`cat` 初始化自 `this.$route.query`，`sort` 默认 `default`

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 关键词搜索 | 输入框回车 | 调用 `apply`，把 `q`、`cat` 写入路由 query |
| 点击筛选 | 点击「筛选」按钮 | 同上，驱动列表重新计算 |
| 切换分类 | 分类下拉 `change` | 立即调用 `apply` 更新路由 query |
| 价格排序 | 排序下拉选择「价格从低到高」 | 仅切换本地 `sort`，计算属性实时重排，不修改路由 |
| 外链带参进入 | 路由 `query.q` / `query.cat` 变化 | `watch` 同步到本地筛选条件 |
| 商品操作 | 点击卡片或加购按钮 | 由 `ProductCard` 处理：进入详情、加购或询价引导 |

## 依赖的组件或工具

- `ProductCard`（`@/components/ProductCard.vue`）：商品卡片
- `money`、`asset`、`fieldValue`（`@/domain/productFields`）：金额、资源路径与空字段工具（本页模板未直接使用，随列表页统一引入）

## 状态与边界

- 筛选与排序均为前端对已载入商品的内存计算，不分页、不请求接口；商品量大时需改为服务端检索
- 无匹配商品时显示「暂无匹配商品，试试更换关键词。」
- 客户资料产品价格为空，参与价格排序时排在最后；页面标注「客户资料产品待报价」
