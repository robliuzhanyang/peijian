# 全部分类（categories.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/categories.vue` |
| 路由地址 | `/categories` |
| 路由名称 | `categories` |
| 业务分组 | 采购入口 |
| 页面标题 | 全部分类 |

## 页面作用

以卡片网格展示全部产品分类。每张分类卡片列出子类标签（chip），并提供「查看全部 →」入口；点击任一子类或查看全部都会携带分类 id 跳转到配件采购列表。

## 数据来源

- `state.categories`：商品分类树（应用启动时 `bootstrap` action 从接口或 mock 载入），每项含 `id`、`name`、`children`（子类名称数组）

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 按子类筛选 | 点击某个子类标签 | 跳转 `/goods?cat=分类id` |
| 查看全部 | 点击「查看全部 →」 | 跳转 `/goods?cat=分类id` |

## 依赖的组件或工具

- `vue-router` 的 `router-link`（全局注册），通过 `query.cat` 向商品列表传参
- 无自定义组件与领域工具引用

## 状态与边界

- 子类标签只携带分类 id，不带具体子类名称参数，落地页按整类过滤
- 分类数据为启动时载入的演示目录，正式分类以后端接口返回为准
