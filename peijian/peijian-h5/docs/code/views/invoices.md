# 发票管理（invoices.vue）

| 项目     | 说明                     |
| -------- | ------------------------ |
| 文件路径 | `src/views/invoices.vue` |
| 路由地址 | `/invoices`              |
| 路由名称 | `invoices`               |
| 业务分组 | 合同与发票               |
| 页面标题 | 发票管理                 |

## 页面作用

页面分上下两区：上区"发票列表"展示每份发票的号码、类型徽章、关联订单号、企业抬头、状态徽章、金额、申请时间与开具时间；下区"可开票订单"列出处于允许开票状态且尚无发票记录的订单，并提供申请开票入口。

## 数据来源

- `businessApi.invoices()`：`created` 时拉取发票数组，mock 模式读取 `catalog.json` 的 `invoices`（种子 3 份：已开具、审核中、已驳回）
- `state.orders`：computed `invoiceableOrders` 筛选状态命中白名单 `['待核款','待发货','运输中','待收货','已完成','售后中']`、且订单 id 未出现在任何发票的 `orderId` 中的订单；订单首次加载时由 `catalog.json` 的 `orders` 种子与本地订单合并、localStorage 持久化
- 发票金额取 `amountFen`，经 `money(fen)` 格式化为元

## 交互说明

| 操作          | 触发                       | 行为                                                                                                                |
| ------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 查看发票      | 点击发票行"查看发票"       | 携带**发票 id** 跳转 `/invoice-detail?id={发票id}`                                                                  |
| 申请开票      | 点击可开票订单行"申请开票" | 携带**订单 id** 跳转 `/invoice-apply?id={订单id}`                                                                   |
| 类型/状态徽章 | 发票行渲染                 | 发票类型固定为 `blue` 徽章；状态由 `invoiceStatusClass` 配色：已开具 `green`、已驳回 `red`、审核中等其余状态 `gold` |
| 申请/开具时间 | 发票行渲染                 | 申请时间 `appliedAt` 常驻；`issuedAt` 存在时追加" · 开具 xxx"                                                       |

## 依赖的组件或工具

- `businessApi`：`@/api` 的发票列表接口
- `money(fen)`：来自 `@/domain/productFields`
- Vuex：读取 `state.orders`
- vue-router：跳转发票详情与开票申请页

## 状态与边界

- 发票列表为空时显示"暂无发票记录。"空态
- "可开票订单"区常驻渲染；没有符合条件的订单时显示"暂无可开票订单。"
- "待付款""已取消"订单不在可开票白名单内；是否具备开票资格的正式规则以后端为准
- mock 模式发票为 `catalog.json` 种子数据，正式发票记录以发票接口返回为准
