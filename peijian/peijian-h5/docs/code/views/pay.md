# 订单支付（pay.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/pay.vue` |
| 路由地址 | `/pay` |
| 路由名称 | `pay` |
| 业务分组 | 交易与履约 |
| 页面标题 | 订单支付 |

## 页面作用

演示订单支付页：展示订单号与应付金额，可在"对公转账 / 线上支付"两种方式间切换，并通过按钮模拟支付成功或失败，不连接任何真实支付通道。

## 数据来源

- `state.orders`：按路由 `query.id` 查找当前订单
- `state.lastOrder`：按 id 未命中时兜底使用最近一次下单结果
- 应付金额取订单快照 `order.totalFen`
- 支付方式列表与选中项为页面本地 data，默认"对公转账"

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 切换支付方式 | 点击方式按钮 | 更新本地 `method` 并高亮当前项 |
| 模拟支付成功 | 点击"模拟支付成功" | commit `setOrderStatus` 将订单置为"已付款"，跳转 `/pay-success?id=订单号` |
| 模拟支付失败 | 点击"模拟支付失败" | 跳转 `/pay-failed`（不携带订单 id） |

选择"对公转账"时展示说明：对公账户资料由后端提供、上传凭证后由财务核款，页面不展示虚构账号。

## 依赖的组件或工具

- `money(fen)`：来自 `@/domain/productFields`
- Vuex：`state.orders`、`state.lastOrder`，mutation `setOrderStatus`
- vue-router：跳转支付成功/失败页

## 状态与边界

- 纯演示流程，不产生真实交易、不接入支付 SDK 或网关
- 订单不存在且无 `lastOrder` 兜底时，显示"订单不存在"空态及"查看订单"链接
- 页面不校验订单状态，任何情况下进入该页都可再次模拟支付
