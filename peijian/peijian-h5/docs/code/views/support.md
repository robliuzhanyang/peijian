# 客户支持（support.vue）

| 项目     | 说明                    |
| -------- | ----------------------- |
| 文件路径 | `src/views/support.vue` |
| 路由地址 | `/support`              |
| 路由名称 | `support`               |
| 业务分组 | 内容与服务              |
| 页面标题 | 客户支持                |

## 页面作用

客户支持聚合页：顶部联系方式卡以三格展示客服热线、服务时间、支持邮箱；下方共 6 张渠道卡片——上排 3 张来自接口配置的支持渠道，下排 3 张为固定快捷入口（产品咨询、订单支持、售后服务）。

## 数据来源

- `businessApi.support()`：`created` 时调用 `load()`（try/catch，失败回退为空信息），mock 模式读取 `catalog.json` 的 `support`：
  - `hotline`（400-880-1688）、`hours`（工作日 8:30 - 18:00）、`email`（service@xinjian-demo.com）
  - `channels`：报价咨询（→ `/quote`）、技术支持（→ `/learning`）、订单与售后（→ `/aftersales`）
- 下排产品咨询（`/goods`）、订单支持（`/orders`）、售后服务（`/aftersales`）三张卡片为模板固定配置，不依赖接口

## 交互说明

| 操作         | 触发             | 行为                                                             |
| ------------ | ---------------- | ---------------------------------------------------------------- |
| 联系方式展示 | 顶部三格渲染     | 显示热线、时间、邮箱；任一字段缺失时对应位置显示"—"              |
| 接口渠道卡片 | 点击上排任一卡片 | 按该渠道 `to` 跳转（`/quote`、`/learning`、`/aftersales`）       |
| 固定快捷卡片 | 点击下排任一卡片 | 产品咨询 →`/goods`、订单支持 →`/orders`、售后服务 →`/aftersales` |

## 依赖的组件或工具

- `businessApi`：`@/api` 的客户支持渠道接口
- vue-router：6 张卡片均为 `<router-link>`
- 全局样式类：`card`、`identity-grid`、`three-col`、`alert`
- 组件声明为 `{ name: 'Page' }`

## 状态与边界

- 接口异常被 catch 后 `info = {}`、`links = []`：联系方式显示"—"，上排渠道卡不渲染，仅保留下排 3 张固定卡片
- 本页为导航聚合页，不承载在线客服、工单创建/查询等业务逻辑
- 页面 `alert` 已明示热线、邮箱及响应承诺为演示信息，正式客服通道以服务接口返回为准
