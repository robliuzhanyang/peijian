# 一站式选购（diy.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/diy.vue` |
| 路由地址 | `/diy` |
| 页面标题 | 一站式选购 |

本页把原“套装直购”和“模块化分步选配”合并为一个流程。用户先选择立式、卧式或悬挂式方案，再按 8 步完成机柜、铝件 5 件套、振镜、场镜、激光器、打标卡、电脑套装和扩展配件选择。

核心规则：

- 机柜自动带出铝件 5 件套；5 件套可展开逐项微调。
- 更换立柱后，光路只保留与新立柱绑定的候选项。
- 激光器与打标卡联动；打标卡继续过滤扩展配件。
- 视频振镜已配套场镜，场镜步骤自动完成。
- 每一步标题右侧均提供“商城选配”入口；底部弹框按当前品类与兼容关系筛选商品，铝件 5 件套支持在弹框内切换五个部件分类。
- 从配件商城加入或更换任一套内项目，会先弹出“破套重算”提醒；确认后仍保留一站式选购流程，但价格切换为“组合价”，即所选商城商品正价之和。
- 未登录仅显示“登录后可见”，演示登录后展示参考价。

相关文件：

- `src/domain/oneStopMixin.js`：H5/PC 共用业务规则与状态机。
- `src/mock/oneStopCatalog.js`：假数据、产品、套件与兼容关系。
- `src/api/oneStop.js`：API 适配层，正式接入时替换为后端请求。
- `src/views/diy-confirm.vue`、`src/views/quote.vue`：配置确认与报价预览。
