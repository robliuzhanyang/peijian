# 登录（login.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/login.vue` |
| 路由地址 | `/login` |
| 路由名称 | `login` |
| 业务分组 | 企业与账号 |
| 页面标题 | 登录 |

## 页面作用

商城登录入口，使用手机号 + 6 位演示验证码的形式。校验通过后进入企业工作台，并提供注册与企业认证入口。

## 数据来源

- 组件 `data`：`mobile`（手机号）、`code`（验证码），均通过 `v-model.trim` 绑定并自动去除首尾空格
- 无登录接口调用；校验失败时通过 Vuex mutation `setNotice` 写入全局提示

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 输入手机号 | 输入框录入 | 双向绑定到 `mobile`，自动去除首尾空格 |
| 输入验证码 | 输入框录入 | 双向绑定到 `code`，自动去除首尾空格 |
| 进入演示工作台 | 点击"进入演示工作台" | 手机号与验证码均通过正则校验时跳转 `/user`；否则提交 `setNotice` 提示"请输入正确手机号和六位演示验证码" |
| 去注册 | 点击"注册与企业认证" | 路由跳转 `/register` |

校验规则：

- 手机号：`/^1\d{10}$/`，以 1 开头、共 11 位数字
- 验证码：`/^\d{6}$/`，恰好 6 位数字

## 依赖的组件或工具

- `router-link`：跳转注册页
- Vue Router：`$router.push('/user')`
- Vuex：mutation `setNotice`

## 状态与边界

- 演示环境不发送短信验证码，输入任意符合规则的 6 位数字即可通过
- 登录成功仅做前端路由跳转，不建立真实登录态，不存储 token
