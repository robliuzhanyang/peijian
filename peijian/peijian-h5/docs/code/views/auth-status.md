# 认证进度（auth-status.vue）

| 项目     | 说明                        |
| -------- | --------------------------- |
| 文件路径 | `src/views/auth-status.vue` |
| 路由地址 | `/auth-status`              |
| 路由名称 | `auth-status`               |
| 业务分组 | 企业与账号                  |
| 页面标题 | 认证进度                    |

## 页面作用

展示企业实名认证的当前状态徽章与"切换企业"入口，并按节点渲染认证审核时间线（节点标题、时间、说明），底部提供查看申请表与企业工作台入口。

## 数据来源

- `businessApi.authFlow()`：`created` 时调用 `load()` 拉取认证节点数组（try/catch，失败回退为空数组），mock 模式读取 `catalog.json` 的 `authFlow`（种子 4 个节点：提交认证资料 → 平台初审 → 企业实名复核 → 认证通过，`state` 均为 done）
- `state.authStatus`：模板直接读取的 Vuex 认证状态，仓库初始化取 `catalog.json` 中 `profile.authStatus`（"已认证"）

## 交互说明

| 操作           | 触发                   | 行为                                                                                                                                                |
| -------------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 当前状态徽章   | 顶部渲染               | 以绿色徽章展示 `state.authStatus`，右侧"切换企业"跳转 `/companies`                                                                                  |
| 认证节点时间线 | 渲染接口返回的 `nodes` | 节点按数组顺序渲染；`state` 为 `active` 用常规样式、`todo` 加 `field-pending` 弱化、`done` 常规；`time` 缺失时显示"时间待更新"，后接节点说明 `desc` |
| 查看申请表     | 点击"查看申请表"       | 路由跳转 `/register`                                                                                                                                |
| 回企业工作台   | 点击"企业工作台"       | 路由跳转 `/user`                                                                                                                                    |

页面为进度展示，无表单与提交动作。

## 依赖的组件或工具

- `businessApi`：`@/api` 的企业认证进度接口
- Vuex：模板直接读取 `state.authStatus`
- vue-router：切换企业、申请表、工作台三处跳转
- 全局样式类：`card`、`between`、`timeline`、`timeline-node`、`field-pending`、`badge`、`alert`、`btn`
- 组件声明为 `{ name: 'Page' }`

## 状态与边界

- 页面只在 `created` 拉取一次，不轮询；接口异常时节点为空，但状态徽章、说明 `alert` 与底部入口仍正常渲染
- 页面 `alert` 已明示：以上为演示认证流程，正式审核节点、材料退回原因以认证接口返回为准
- Vuex 中的认证状态不代表服务端真实认证结果
