# 搜索与联想（search.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/search.vue` |
| 路由地址 | `/search` |
| 路由名称 | `search` |
| 业务分组 | 采购入口 |
| 页面标题 | 搜索与联想 |

## 页面作用

商品关键词检索页：在输入框输入产品名称、系列、产品型号或可售 SKU 的关键词，回车或点击「搜索」后展示匹配结果网格，并显示结果数量；无结果时展示空态。

## 数据来源

全部来自 Vuex，检索在前端内存中完成：

- `state.products`：计算属性 `products` 在 `name`、`model`、`skuCode`、`series` 四个字段中做不区分大小写的包含匹配，并兼容分类参数 `cat`
- `state.categories`：保留同构数据来源（本页模板未渲染分类入口）
- 关键词 `q` 初始化自 `this.$route.query.q`；`cat`、`sort` 与配件采购页保持同构

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 提交关键词 | 输入框回车 | 调用 `apply`，把 `q`、`cat` 写入路由 query 并刷新结果 |
| 点击搜索 | 点击「搜索」按钮 | 同上 |
| 外链带参进入 | 路由 `query.q` / `query.cat` 变化 | `watch` 同步到本地查询条件 |
| 商品操作 | 点击卡片或加购按钮 | 由 `ProductCard` 处理：进入详情、加购或询价引导 |

## 依赖的组件或工具

- `ProductCard`（`@/components/ProductCard.vue`）：商品卡片
- `money`、`asset`、`fieldValue`（`@/domain/productFields`）：金额、资源路径与空字段工具（本页模板未直接使用）

## 状态与边界

- 页面标题（路由 meta）为「搜索与联想」，页内 H1 为「搜索商品」；当前代码实现为关键词即时过滤，未实现下拉联想/补全交互
- 检索范围仅限已载入的本地商品，不调用搜索接口、不分页
- 无结果时显示「没有搜索结果。」
