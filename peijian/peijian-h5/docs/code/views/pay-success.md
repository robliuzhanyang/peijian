# 支付成功（pay-success.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/pay-success.vue` |
| 路由地址 | `/pay-success` |
| 路由名称 | `pay-success` |
| 业务分组 | 交易与履约 |
| 页面标题 | 支付成功 |

## 页面作用

演示支付成功的结果反馈页，提示订单已进入后续履约流程，并给出"查看订单"和"返回首页"两个出口。

## 数据来源

- 仅读取路由 `query.id` 用于展示订单号，缺省时显示"—"
- 不读取 Vuex、不调用任何接口

## 交互说明

无交互，仅展示原型占位。

## 依赖的组件或工具

- vue-router `<router-link>`：跳转订单详情（透传 `query.id`）与首页
- 组件声明为 `{ name: 'Page' }`，无业务工具依赖

## 状态与边界

- 纯结果占位页，不校验订单是否真实存在，本页也不修改订单状态（状态变更发生在支付页模拟成功时）
- "查看订单""返回首页"仅为静态路由入口
