# 商城首页（home.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/home.vue` |
| 路由地址 | `/home` |
| 路由名称 | `home` |
| 业务分组 | 采购入口 |
| 页面标题 | 商城首页 |

## 页面作用

商城首页：顶部品牌横幅提供「逛配件」入口，中部为配件/套装/选配/订单四个快捷入口，下方分别展示「客户资料产品」与「演示推荐」两个商品网格。

## 数据来源

全部来自 Vuex，无独立接口调用：

- `state.products`：商品目录（应用启动时 `bootstrap` action 从接口或 mock 载入）
- 计算属性 `customer`：过滤 `sourceType === 'customer'` 的客户资料产品
- 计算属性 `hot`：过滤 `hot` 标记商品并截取前 4 件作为演示推荐
- 横幅图片通过 `asset('machine.svg')` 取静态资源

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 逛配件 | 点击横幅「逛配件」 | 跳转 `/goods` |
| 快捷入口 | 点击配件/套装/选配/订单 | 分别跳转 `/goods`、`/package`、`/diy`、`/orders` |
| 商品操作 | 点击商品卡片或卡片按钮 | 由 `ProductCard` 内部处理：进入详情、加购或询价引导 |

## 依赖的组件或工具

- `ProductCard`（`@/components/ProductCard.vue`）：商品卡片，统一展示图片、系列/型号/SKU、价格库存与购买动作
- `asset(path)`（`@/domain/productFields`）：拼接静态资源路径
- `money`、`fieldValue`：同文件引入的金额格式化与空字段占位工具（本页模板未直接使用）

## 状态与边界

- 页面已明确标注「价格和库存为演示信息」
- 客户资料产品可能缺少报价，卡片上显示「待报价」并引导咨询
- 商品目录由启动流程异步载入，载入前两个网格为空，无骨架屏
