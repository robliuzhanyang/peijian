# 采购合同（contracts.vue）

| 项目     | 说明                      |
| -------- | ------------------------- |
| 文件路径 | `src/views/contracts.vue` |
| 路由地址 | `/contracts`              |
| 路由名称 | `contracts`               |
| 业务分组 | 合同与发票                |
| 页面标题 | 采购合同                  |

## 页面作用

页面分上下两区：上区"合同列表"展示每份合同的编号、标题、关联订单号、买方企业、金额、状态徽章与签署时间；下区"可申请合同的订单"列出尚无合同覆盖的有效订单，并提供合同预览入口。

## 数据来源

- `businessApi.contracts()`：`created` 时拉取合同数组，mock 模式读取 `catalog.json` 的 `contracts`（种子 2 份：一份"已生效"、一份"待买方签署"）
- `state.orders`：computed `availableOrders` 从订单列表中筛出 id 未被任何合同的 `orderId` 覆盖、且状态不为"待付款""已取消"的订单；订单首次加载时由 `catalog.json` 的 `orders` 种子与本地订单合并、localStorage 持久化
- 合同金额取 `amountFen`，经 `money(fen)` 格式化为元

## 交互说明

| 操作     | 触发                                    | 行为                                                                          |
| -------- | --------------------------------------- | ----------------------------------------------------------------------------- |
| 查看合同 | 点击合同行"查看合同"                    | 携带**合同 id** 跳转 `/contract-detail?id={合同id}`                           |
| 合同预览 | 点击可申请订单行"合同预览"              | 携带**订单 id** 跳转 `/contract-detail?id={订单id}`（详情页支持按订单号反查） |
| 状态徽章 | 列表渲染时由 `contractStatusClass` 配色 | "已生效"为 `green`，其余状态（待买方签署）为 `gold`                           |
| 签署时间 | 列表渲染                                | 取 `signedAt`，为空时显示"待签署"                                             |

## 依赖的组件或工具

- `businessApi`：`@/api` 的合同列表接口
- `money(fen)`：来自 `@/domain/productFields`
- Vuex：读取 `state.orders`
- vue-router：跳转合同详情页

## 状态与边界

- 合同列表为空时显示"暂无合同记录。"空态
- "可申请合同的订单"区使用 `v-if`，没有符合条件的订单时整块不渲染；订单行文案注明"合同待平台生成"
- 合同正文、金额与双方主体均以合同接口返回为准；可申请范围（当前仅排除待付款/已取消）的正式规则以后端为准
