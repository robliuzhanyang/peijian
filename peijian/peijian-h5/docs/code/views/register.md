# 注册与企业认证（register.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/register.vue` |
| 路由地址 | `/register` |
| 路由名称 | `register` |
| 业务分组 | 企业与账号 |
| 页面标题 | 注册与企业认证 |

## 页面作用

企业资料演示表单，填写企业名称、统一社会信用代码、联系人、联系电话后提交演示认证，提交后将认证状态置为"审核中（演示）"并跳转认证进度页。

## 数据来源

- 组件 `data`：`company`（企业名称）、`credit`（统一社会信用代码）、`contact`（联系人）、`phone`（联系电话），均通过 `v-model.trim` 绑定
- 提交时通过 Vuex mutation `setAuth` 写入 `state.authStatus`，无认证接口调用

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 填写企业资料 | 四个输入框录入 | 双向绑定到对应字段，自动去除首尾空格 |
| 提交演示认证 | 点击"提交演示认证" | 四项全部非空时：提交 `setAuth('审核中（演示）')` 并跳转 `/auth-status`；任一项为空时提交 `setNotice` 提示"请补齐企业资料" |

## 依赖的组件或工具

- Vue Router：`$router.push('/auth-status')`
- Vuex：mutation `setAuth`（写入认证状态）、`setNotice`（校验提示）

## 状态与边界

- 仅做四项"非空"校验，未校验统一社会信用代码格式与手机号格式
- 营业执照附件上传、审核结果、企业身份均由正式认证接口管理，本页不涉及
- 认证状态变化只发生在前端 Vuex，刷新后状态取决于 store 的初始逻辑，不代表服务端审核结果
