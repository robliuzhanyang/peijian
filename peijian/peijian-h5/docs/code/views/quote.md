# 采购报价单（quote.vue）

| 项目     | 说明                  |
| -------- | --------------------- |
| 文件路径 | `src/views/quote.vue` |
| 路由地址 | `/quote`              |
| 路由名称 | `quote`               |
| 业务分组 | 选型与采购            |
| 页面标题 | 采购报价单            |

## 页面作用

采购报价预览页：以表格列出所选真实组合的产品名称、型号、可售 SKU、数量、单价，并在底部显示合计金额；可返回选配页修改组合。

- **组合信息条**（有 `selectedScheme` 时）：组合名称、标签徽章（动态配色）、自定义调整的金色徽章、组合型号、加工方向中文名、适用场景、总件数
- **报价明细表分两层**（组合快照来源，含真实组合直选与自定义调整）：
  - 分段行「主体构成：立柱 · 光路 · 运动轴 · 底板 · 机箱（N 项）」（蓝底）
  - core 各行：名称（含模块名小字）、型号、SKU、数量、单价
  - 分段行「配套附件：随组合提供的辅助件（M 项）」（琥珀底）
  - extras 各行；无配套附件时显示「该组合无单列配套附件。」
- 无组合快照时回退为按 `state.selected` 逐行展示（数量 1）

## 数据来源

- `state.selectedScheme`：组合快照，`parts` 每行含 `{ module, id, qty, section }`；`customized: true` 表示自定义调整
- `state.selected`：部品 id 数组（无快照时使用）
- `getters.product(id)`：解析名称、`model`、`skuCode`、`priceFen`，未命中返回 `{}`
- 计算属性：
  - `rows`：组合模式取 `parts`，否则把 selected 映射为 `{ id, qty: 1 }`
  - `coreRows` / `extrasRows`：按 `section` 过滤，缺标记的旧快照视为 core
  - `partCount`：总件数（含数量）
  - `total`：合计；**任一行 `priceFen == null` 即整体返回 `null`**，由 `money` 渲染「待报价」
- 页面不调用任何报价接口

## 交互说明

| 操作     | 触发             | 行为                 |
| -------- | ---------------- | -------------------- |
| 修改组合 | 点击「修改组合」 | 跳转 `/diy` 重新选配 |

表格为只读预览，无行内编辑或提交动作。

## 依赖的组件或工具

- `money(fen)`：单价与合计金额格式化，`null` 渲染「待报价」
- `fieldValue(value)`：型号/SKU 空值显示「待补充」
- `getters.product`：按 id 解析报价部品
- `@/mock/catalog.json` 的 `directions`：方向 id 转中文名
- `vue-router` 的 `router-link`：返回修改入口

## 状态与边界

- 页头标注「所列部品为客户资料，型号可核对、价格待业务确认」
- `rows` 为空时显示「没有组合，请先选配或查看真实组合。」
- 真实组合部品全部 `priceFen:null`，各行单价与合计统一为「待报价」，不存在 ¥0.00；正式价格以业务报价为准
