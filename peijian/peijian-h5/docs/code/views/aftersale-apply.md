# 申请售后（aftersale-apply.vue）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/views/aftersale-apply.vue` |
| 路由地址 | `/aftersale-apply` |
| 路由名称 | `aftersale-apply` |
| 业务分组 | 内容与服务 |
| 页面标题 | 申请售后 |

## 页面作用

售后申请表单页：选择申请类型（退货退款 / 仅退款 / 维修换货）、填写问题描述、演示选择本地附件；校验问题描述非空后，携带订单 id 与申请类型跳转售后进度页（`/aftersale-detail`）。

## 数据来源

- `route.query.id`：来源订单 id，页头展示；未携带时显示"未选择"
- 表单数据全部保存在本页 `data` 中，初始值：`type: '退货退款'`、`reason: ''`、`filename: ''`
- 附件只读取本地文件选择框的文件名用于展示，不上传、不落库
- 无接口调用，申请不写入 Vuex

## 交互说明

| 操作 | 触发 | 行为 |
| --- | --- | --- |
| 选择申请类型 | 操作下拉框 | `v-model` 绑定 `type`，可选项为退货退款 / 仅退款 / 维修换货 |
| 填写问题描述 | 输入文本域 | `v-model.trim` 绑定 `reason`，自动去除首尾空白 |
| 选择附件 | 文件框 `change` | 取所选文件的 `name` 写入 `filename` 并在下方小字展示；未选文件为空 |
| 保存演示申请 | 点击"保存演示申请"，描述为空 | 提交 `setNotice` 提示"请填写问题描述"，中断跳转 |
| 保存演示申请 | 点击"保存演示申请"，描述非空 | 跳转 `/aftersale-detail?id={订单id}&type={申请类型}` |

## 依赖的组件或工具

- Vuex mutation `setNotice`：表单校验失败时写入全局轻提示
- `router.push`：校验通过后携带 `id`、`type` 查询参数跳转售后进度页（路由 `aftersale-detail`，标题"售后进度"）
- 全局样式类：`card form`、`review-field`、`btn primary`

## 状态与边界

- 整页为演示表单：不提交任何服务端申请，附件不做真实上传，刷新后表单内容丢失
- 仅校验"问题描述非空"；不校验订单是否存在、是否超过售后期、是否重复申请
- 申请类型与问题描述不会被后续页面持久化，售后进度页只能拿到路由上的 `id` 与 `type`
- 正式的售后单创建、附件上传、审核与退款流程均待售后接口提供
