# 企业工作台（user.vue）

| 项目     | 说明                 |
| -------- | -------------------- |
| 文件路径 | `src/views/user.vue` |
| 路由地址 | `/user`              |
| 路由名称 | `user`               |
| 业务分组 | 企业与账号           |
| 页面标题 | 企业工作台           |

## 页面作用

登录后的企业采购入口页。顶部概览区展示企业名称、联系人/岗位、认证状态与待办提醒（待付款、待收货笔数），并提供查看订单、查看认证两个按钮；下方功能宫格聚合订单、合同、发票、积分、常用方案、收货地址、售后、账号设置 8 个常用业务入口，订单与售后宫格带待办角标。

## 数据来源

- `businessApi.profile()`：`created` 时调用 `load()` 拉取用户与企业资料（try/catch，失败不阻塞页面），mock 模式读取 `catalog.json` 的 `profile`，使用字段 `companyName`、`name`、`role`
- `state.authStatus`：概览区直接读取 Vuex 认证状态，仓库初始化取 `profile.authStatus`（"已认证"）
- `state.orders`：三个 computed 待办数的数据源——`pendingPay`（状态为"待付款"的笔数）、`pendingReceive`（状态为"待收货"的笔数）、`aftersaleCount`（状态为"售后中"的笔数）；订单首次加载时由 `catalog.json` 的 `orders` 种子与本地订单合并、localStorage 持久化
- 宫格配置 `links`：组件 data 内的静态数组，每项含 `key`（关联角标）、`name`、`to`、`desc`

## 交互说明

| 操作                | 触发                    | 行为                                                                                                                                                                                 |
| ------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 待办提醒            | 概览区按 computed 渲染  | `pendingPay` 大于 0 时显示"有 N 笔订单待付款，另有 M 笔待收货订单"；为 0 时显示"暂无待办事项，祝采购顺利"                                                                            |
| 查看订单 / 查看认证 | 点击概览区按钮          | 分别跳转 `/orders`、`/auth-status`                                                                                                                                                   |
| 功能宫格            | 点击 8 个入口任一       | 按该项 `to` 跳转：订单 `/orders`、合同 `/contracts`、发票 `/invoices`、积分 `/points-ledger`、常用方案 `/favorites`、收货地址 `/addresses`、售后 `/aftersales`、账号设置 `/settings` |
| 宫格角标            | 渲染时调用 `badge(key)` | "订单"宫格显示待付款笔数，"售后"宫格显示售后中笔数，均为红色徽章；其余入口恒返回 0，角标不渲染                                                                                       |

## 依赖的组件或工具

- `businessApi`：`@/api` 的用户与企业资料接口
- Vuex：读取 `state.authStatus`、`state.orders`
- vue-router：概览按钮与宫格跳转
- 全局样式类：`hero-simple`、`link-grid`、`badge red`、`btn`

## 状态与边界

- `profile` 接口失败时回退为空对象：企业名称显示兜底文案"企业采购中心"，宫格与待办仍可正常渲染
- 页面不做权限控制，各宫格入口是否可用与认证状态无关
- 认证状态来自前端 Vuex，不代表服务端真实认证结果；登录为演示流程，进入本页不代表建立了真实登录态
- 待办数量基于本地订单（含 `catalog.json` 种子订单）实时计算，正式待办以服务端数据为准
