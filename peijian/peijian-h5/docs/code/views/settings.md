# 账号设置（settings.vue）

| 项目     | 说明                     |
| -------- | ------------------------ |
| 文件路径 | `src/views/settings.vue` |
| 路由地址 | `/settings`              |
| 路由名称 | `settings`               |
| 业务分组 | 企业与账号               |
| 页面标题 | 账号设置                 |

## 页面作用

账号设置聚合页：上半部分"资料摘要"以 6 格展示个人与企业资料（联系人、手机号、岗位角色、所属企业、认证状态、联系邮箱）；下半部分以列表行聚合个人资料、企业资料、多企业身份、收货地址 4 个设置入口。

## 数据来源

- `businessApi.profile()`：`created` 时调用 `load()` 拉取（try/catch，失败回退为空对象），mock 模式读取 `catalog.json` 的 `profile`，使用字段 `name`、`mobile`、`role`、`companyName`、`email`
- `state.authStatus`：资料摘要中"认证状态"一格直接读取 Vuex，仓库初始化取 `profile.authStatus`（"已认证"）

## 交互说明

| 操作          | 触发                             | 行为                                                                                    |
| ------------- | -------------------------------- | --------------------------------------------------------------------------------------- |
| 资料摘要 6 格 | 页面渲染                         | 联系人、手机号、岗位角色、所属企业、认证状态、联系邮箱；除认证状态外各字段缺失时显示"—" |
| 登录 / 管理   | 点击"个人资料与手机号"行右侧链接 | 路由跳转 `/login`                                                                       |
| 认证状态      | 点击"企业资料"行右侧链接         | 路由跳转 `/auth-status`                                                                 |
| 切换企业      | 点击"多企业身份"行右侧链接       | 路由跳转 `/companies`                                                                   |
| 管理地址      | 点击"收货地址"行右侧链接         | 路由跳转 `/addresses`                                                                   |

页面无表单与设置项开关，所有操作均为页面跳转。

## 依赖的组件或工具

- `businessApi`：`@/api` 的用户与企业资料接口
- Vuex：模板直接读取 `state.authStatus`
- vue-router：4 处站内跳转
- 全局样式类：`card`、`identity-grid`、`order-line`、`tiny`

## 状态与边界

- 本页仅做资料展示与导航聚合，不支持在本页修改任何资料
- 接口异常时 `profile` 回退为空对象，除认证状态外各格显示"—"，页面不阻塞
- 列表下方注明"密码、隐私与通知设置由正式账号接口提供"，当前未实现；正式资料以账号接口返回为准
