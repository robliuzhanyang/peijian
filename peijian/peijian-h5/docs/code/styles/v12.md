# 全局基础样式（styles/v12.css）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/styles/v12.css` |
| 样式层级 | 设计令牌 + 全局基础与全量组件样式（H5/PC 共用） |
| 外部依赖 | 无外部字体与 UI 框架，仅引用本地 `xj-sans.woff` |

## 分区结构（与源码中的注释横幅对应）

1. 自定义字体 `@font-face`（XJ Sans）
2. 设计令牌：`:root` CSS 变量（工业蓝主色、文本/分割线色、语义色、阴影）
3. 基础重置与排版：盒模型、正文、链接、表单控件、图片、标题字号、通用工具类（muted/tiny/btn/card/badge/price 等）
4. PC 页面框架：公告条、品牌头、搜索框、主导航、页脚
5. 商品陈列与详情：商品网格/卡片、筛选侧栏、表格、分页、图库、SKU 选型、套装与选配布局
6. 账号中心与订单履约：侧导航、企业横幅、订单卡片、步骤条、物流时间线、登录注册表单
7. 合同单据：sheet-doc 纸质合同预览（水印、印章、落款）
8. 积分与内容服务：积分横幅、台账、学习卡片、文章、客户支持、推荐码、地址、消息、骨架屏
9. 全局弹层：overlay 遮罩、dialog、drawer 抽屉、原型演示悬浮入口、toast、打印辅助类
10. H5 专属适配：独立导航、信息顺序、底部操作栏避让

## 设计约定

- 颜色、圆角、阴影统一取自 `:root` 变量，禁止散落硬编码（局部特殊值除外）
- 主色 `--blue:#1554c7`，价格色 `--red`，积分色 `--gold`
- H5 端覆盖样式以 `.app.h5` 为前缀；移动端框架样式部分位于 app.css
