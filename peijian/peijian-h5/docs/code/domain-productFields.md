# 领域工具：产品字段（domain/productFields.js）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/domain/productFields.js` |
| 文件角色 | 领域层：客户表《配件》的字段定义与通用展示函数 |
| 两端差异 | H5 / PC 完全共用 |

## 常量定义

| 导出名 | 结构 | 用途 |
| --- | --- | --- |
| `viewFields` | `[键名, 中文标签][]` | 产品五视图：正视、侧视、背面、下视、上视（透视图 perspective 不计入） |
| `physicalFields` | `[键名, 中文标签, 单位][]` | 实物参数：长/宽/高/材质/重量/颜色/轴长/是否电动 |
| `downloadFields` | `[键名, 中文标题][]` | 工程文件：外形装配 3D、产品工程图 PDF、包装工程图 |

## 工具函数

### fieldValue(value, unit?)

空值（null/undefined/空串）显示"待补充"；布尔值转"是/否"；其他值转字符串并按需拼接单位。

### money(fen)

金额单位为分。空值显示"待报价"，否则格式化为 `¥xx.xx`（两位小数）。

### asset(path)

拼接 `BASE_URL + assets/` 前缀；无扩展名的资源名自动补 `.svg`；空值返回 null。

## 设计约定

- 客户未提供的资料一律保持 null，界面显示占位文案，不生成虚构参数
- 单位（mm/kg）为展示建议，待客户正式资料确认
