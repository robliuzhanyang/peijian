# 路由表（router/index.js）

| 项目 | 说明 |
| --- | --- |
| 文件路径 | `src/router/index.js` |
| 路由模式 | hash（`#/path`，静态部署无需服务端回退） |
| 加载方式 | 所有页面 `() => import()` 懒加载，按页生成 chunk |
| 两端差异 | H5 / PC 路由表完全一致 |

## 路由元信息

每条路由带 `meta.title`（浏览器标题，由 App.vue 监听拼接后缀）与 `meta.group`（业务分组）。

## 业务分组与页面

| 分组 | 页面（路由） |
| --- | --- |
| 采购入口 | 商城首页 `/home`、全部分类 `/categories`、配件采购 `/goods`、搜索与联想 `/search` |
| 选型与采购 | 商品详情 `/detail`、一站式选购兼容入口 `/package`、历史套装编辑 `/package-detail`、一站式选购 `/diy`、选配方案确认 `/diy-confirm`、采购报价单 `/quote` |
| 交易与履约 | 购物车 `/cart`、确认订单 `/checkout`、订单支付 `/pay`、支付成功/失败、我的订单、订单详情、物流跟踪 |
| 合同与发票 | 采购合同、合同预览与回传、发票管理、单笔开票、发票详情 |
| 积分与营销 | 积分商城/详情/确认/明细、推荐有礼、常用套装与方案 |
| 内容与服务 | 学习专区、文章详情、客户支持、消息通知、售后列表/申请/进度 |
| 企业与账号 | 企业工作台、登录、注册与企业认证、认证进度、切换企业、收货地址、地址编辑、账号设置 |
| 原型验收 | 状态与异常样式 `/states` |

## 特殊规则

- `/` 重定向到 `/home`
- 未匹配的任意路径 `*` 重定向到 `/home`
- `src/views/index.vue` 为原型入口占位页，未在路由表注册
